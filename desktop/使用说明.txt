股票分析助手 v1.0 —— 使用说明
==================================================

一、这是什么
--------------------------------------------------
一个免安装的 Windows 桌面小工具。双击 exe 就能用，输入股票代码或名称，
联网抓取行情后自动画出 K 线图，并给出一份通俗、分层的技术面分析。
支持 A 股（沪 / 深）、港股、美股。整个程序是单文件，不需要装 Python，
也不需要任何配置文件。运行时需要联网。

二、怎么用
--------------------------------------------------
1. 双击「股票分析助手.exe」（首次启动约需 3~8 秒解压，属正常现象）。
2. 在左上角输入框里输入股票，回车即可：
     代码：600519、000001、300750、00700、AAPL
     名称：贵州茅台、平安银行、腾讯控股、苹果
   输入名称时会先在候选里找完全匹配的那一只，找不到才弹选择框。
3. 顶部工具栏：
     分时 / 日K / 周K / 月K   —— 切换周期
     前复权 / 不复权 / 后复权 —— 切换复权方式
     MACD / KDJ / RSI        —— 切换副图指标
     刷新                    —— 重新抓取数据
     ☆ 加自选 / 自选股        —— 收藏常用标的（保存在本机）
     导出                    —— 导出 K 线 CSV 或完整分析报告 TXT
4. 图表操作：
     滚轮          缩放
     按住左键拖动   平移
     鼠标移动       十字光标，跟随显示该根 K 线的价格与指标

三、右侧面板都有什么
--------------------------------------------------
  · 盘口速览      今开 / 昨收 / 最高 / 最低 / 成交量额 / 振幅 / 换手 / 量比 / 涨停跌停 / 均价
  · 估值与规模    总市值 / 流通市值 / 市盈率 / 市净率 / 每股净资产 / 总股本
  · 技术指标快照  MA5~MA60 / DIF / DEA / KDJ / RSI / 布林三轨 / ATR
  · 资金流向      当日与近 5 日主力、超大单、大单、中单、小单净额
  · 财务摘要      最新报告期的营收、利润、ROE、毛利率、负债率、每股指标
  · 综合诊断      0~100 技术面评分 + 一句话结论 + 白话版解释 + 摘要
  · 多空信号对照  把所有看多、看空信号分开列出来，红=支撑、绿=压制
  · 分维度评分    趋势 / 动量 / 量能 / 位置 四条打分条，一眼看出短板在哪
  · 波动与风险    ATR、年化波动率、布林带宽、最大回撤、风险等级
  · 关键价位阶梯  把上方压力、当前价、下方支撑排成一条阶梯，并给出距离百分比
  · 详细分析      趋势 / 动量 / 量能资金 / 位置成本 / 波动风险 / K线形态与缺口 六大段
  · 情景应对      向上突破、回踩确认、跌破关键位、波动参考 四种条件下的应对参考

四、数据来源
--------------------------------------------------
行情、K 线、资金流、财务数据来自东方财富公开接口；
K 线在东方财富不可用时自动切换到腾讯财经作为备源。
界面左下角会显示当前实际使用的数据来源。
数据带有分钟级延迟，收盘后为当日最终数据。

五、常见问题
--------------------------------------------------
Q：提示「获取失败」怎么办？
A：先确认电脑能上网；稍等十几秒再点「刷新」。东方财富对高频请求会临时限流，
   程序已内置腾讯财经备源和多节点重试，多试一次通常就好。

Q：查不到某只股票？
A：试试直接输 6 位代码（A 股）、5 位代码（港股）或纯英文代码（美股，如 AAPL、
   TSLA、NVDA）。名称搜索依赖接口返回结果，冷门名称可能匹配不到。

Q：自选股存在哪？换电脑会丢吗？
A：存在本机 %APPDATA%\StockAnalyzer\config.json 里，换电脑不会同步。

Q：为什么美股 / 港股没有涨跌停、换手率等字段？
A：这些字段由数据源提供，海外市场部分字段缺失，界面会显示「—」，属正常现象。

Q：exe 有多大？为什么启动慢？
A：约 11 MB，是包含 Python 运行时的单文件程序。首次运行要解压到临时目录，
   所以比普通软件慢一点，之后启动会快一些。
