股票分析助手 · 手机版 使用说明
==================================================

一、这是两个东西，挑一个用
--------------------------------------------------
1) 股票分析助手.apk
   真安卓应用，装到手机上，桌面会有图标。功能与电脑版一致。
   装法：把 apk 传到手机 -> 点击安装 -> 系统提示「未知来源」时选择允许。

2) 股票分析助手.html
   单文件网页。不想装 apk 的话，把这个文件传到手机，
   用浏览器打开即可；也可以在浏览器菜单里选「添加到主屏幕」，
   效果接近一个 App。
   注意：请用手机浏览器打开本地文件，不要用微信内置浏览器
   （微信会拦截本地 html 和外部请求）。

两个版本内核完全一样——同一套图表、同一套分析引擎、同一套数据源。

二、怎么用
--------------------------------------------------
1. 顶部输入框输入股票，回车或点「查询」：
     代码：600519 / 000001 / 300750 / 00700 / AAPL
     名称：贵州茅台 / 平安银行 / 腾讯控股 / 苹果
   输入名称会先找完全匹配的那只，找不到才弹出候选列表让你选。
2. 第二行三个开关：
     分时 / 日K / 周K / 月K      —— 切换周期
     前复权 / 不复权 / 后复权     —— 切换复权方式
     MACD / KDJ / RSI            —— 切换副图指标
3. 图表手势：
     双指张合    缩放
     单指拖动    左右平移
     轻点屏幕    开关十字光标（显示该根 K 线的开高低收）
4. 上下滑动查看完整分析；「详细分析」六大段默认展开第一段，点标题可折叠。

三、右侧（下方）面板都有什么
--------------------------------------------------
  · 盘口速览      今开 / 昨收 / 最高 / 最低 / 量额 / 振幅 / 换手 / 量比 / 涨跌停 / 均价
  · 估值与规模    总市值 / 流通市值 / 市盈率 / 市净率 / 每股收益
  · 技术指标快照  MA5~MA60 / DIF / DEA / KDJ / RSI / 布林三轨 / ATR
  · 资金流向      当日与近 5 日主力、超大单、大单、中单、小单净额
  · 财务摘要      最新报告期营收、利润、ROE、毛利率、负债率、每股指标（仅 A 股）
  · 综合诊断      0~100 分 + 一句话结论 + 白话版解释 + 摘要
  · 多空信号对照  看多、看空信号分列，红=支撑、绿=压制
  · 分维度评分    趋势 / 动量 / 量能 / 位置 四条打分条，一眼看出短板
  · 波动与风险    ATR、年化波动率、布林带宽、最大回撤、风险等级
  · 关键价位阶梯  上方压力、当前价、下方支撑排成阶梯，附距离百分比
  · 详细分析      趋势 / 动量 / 量能资金 / 位置成本 / 波动风险 / K线形态与缺口
  · 情景应对      向上突破、回踩确认、跌破关键位、波动参考 四种条件的应对参考

四、数据来源
--------------------------------------------------
K 线、分时、实时快照：腾讯财经（主源，稳定且响应快）
资金流、财务数据、大盘基准：东方财富（辅源，偶发限流会自动重试）
所有接口失败时程序会自动降级：拿不到的部分显示「暂不可用」，不影响其余分析。
数据为分钟级延迟，收盘后为当日最终数据。

五、常见问题
--------------------------------------------------
Q：后复权模式下价格怎么和行情软件不一样？
A：后复权价格本身就会被放大（茅台后复权价在 8000 以上），这是正常的。
   为保持一致，切到后复权时，行情头和价位阶梯都会统一用后复权口径，
   标题右侧会标注「后复权价」，涨跌停字段则隐藏（该字段只有不复权口径才有意义）。

Q：提示「获取失败」或某块显示「暂不可用」？
A：先确认手机能联网，再点一次「查询」。东方财富对高频请求会临时限流，
   程序已内置腾讯财经兜底和多节点重试，重试通常即可恢复。

Q：港股 / 美股为什么没有换手率、量比、涨跌停？
A：这些字段由数据源决定，海外市场部分字段缺失属正常现象，会显示「—」。

Q：能离线看吗？
A：不能。行情数据必须联网获取，程序本身不含历史数据。

Q：自选股怎么用？
A：查到一只股票后，点行情头右侧的 ☆ 加入自选（变黄即已收藏）。
   顶栏「自选」按钮打开列表：一次批量刷新全部现价和涨跌幅，点一行直接查看，
   点右侧 × 移出。最多 50 只，保存在本机浏览器/应用里，不上传。

Q：纯血鸿蒙（HarmonyOS NEXT）能用吗？
A：APK 不能——纯血鸿蒙没有安卓兼容层，装不了任何 apk。
   但「股票分析助手.html」可以：用鸿蒙自带浏览器打开这个文件即可，
   功能与 App 完全一致；浏览器菜单里选「添加到主屏幕」，体验接近原生应用。
   iPhone / iPad 同理。
